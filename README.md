# textgame🎮

Консольный текстовый квест, написанный на Go. Игрок перемещается по комнатам, собирает вещи в рюкзак и взаимодействует с окружением, чтобы выбраться на улицу и успеть в универ.

Проект примечателен своей **архитектурой**: игровой движок полностью изолирован от сюжета. Здесь нет громоздких `if/switch` и захардкоженных проверок — вся логика строится на динамическом взаимодействии структур, мапах и анонимных функциях.

## ✨ Фичи и Архитектура

* **Паттерн Command (Диспетчер команд):** Обработка ввода реализована через карту функций `map[string]func([]string) string`. Добавление новой команды занимает пару строк и не требует изменения основного цикла игры.
* **Динамическое состояние мира:** Описания комнат генерируются "на лету" с помощью функций. Если игрок забирает ключи со стола, они навсегда исчезают из описания локации.
* **Универсальные триггеры и замки:** Система путей (`ways`), блокировок (`locks`) и действий (`triggers`). Предметы не привязаны к конкретным комнатам жестким кодом — всё настраивается на этапе инициализации (`initGame`).
* **Изолированный контекст:** Функции взаимодействия (`take`, `useTo`, `putOn`, `goTo`) ничего не знают о сюжете. Они просто работают с состоянием текущей комнаты и инвентарем игрока.

## 🕹️ Доступные команды

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `осмотреться` | Показывает подробное описание текущей комнаты и доступные выходы | `осмотреться` |
| `идти <комната>` | Перемещение в другую локацию (если путь открыт) | `идти коридор` |
| `взять <предмет>` | Положить предмет из комнаты в инвентарь (требуется рюкзак) | `взять ключи` |
| `надеть <предмет>` | Надеть предмет на себя | `надеть рюкзак` |
| `применить <предмет> <цель>` | Использовать предмет из инвентаря на объект в комнате | `применить ключи дверь` |
