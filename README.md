# textgame

Текстовый квест: собрать рюкзак и дойти до универа.

## Запуск

```bash
go run .
go run . -fast       # без эффекта печатной машинки
go run . -no-color   # без ANSI-цветов
go run . -color      # цвета принудительно (например, в старом cmd.exe)
```

Выйти можно командой `выход` (или `quit`, `exit`), а в Windows — ещё и Ctrl+Z + Enter.

## Команды

| Команда | Что делает |
| --- | --- |
| `осмотреться` | посмотреть вокруг |
| `идти <место>` | перейти в комнату (кухня, коридор, комната, улица) |
| `взять <предмет>` | положить предмет в рюкзак |
| `надеть <предмет>` | надеть рюкзак (иначе некуда класть вещи) |
| `применить <предмет> <цель>` | например, `применить ключи дверь` |
| `инвентарь` | показать, что в рюкзаке |
| `карта` | показать доступные выходы |
| `помощь` | список команд |
| `заново` | начать игру сначала |
| `выход` | выйти |

Регистр и лишние пробелы не важны: `Идти   Коридор` работает так же, как `идти коридор`.
